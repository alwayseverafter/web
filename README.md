# AlwaysEverafter

Premium digital invitation website for AlwaysEverafter.

The application lives in [aea-invitations](aea-invitations/README.md).

```sh
cd aea-invitations
npm install
npm run dev
```

Production build: `npm run build`. Local production preview: `npm run preview`.

See [verification notes](aea-invitations/VERIFICATION.md) for the implemented features and checks.
