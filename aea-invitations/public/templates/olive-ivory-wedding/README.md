# Olive & Ivory Wedding — source reconstruction

A standalone, responsive HTML/CSS/JavaScript reconstruction of the published Olive & Ivory wedding invitation, based on the saved visible site content and design notes available in the ChatGPT conversation.

## Run locally

Open `index.html` in a browser. No build tools are required. Google Fonts are loaded online; the site still falls back to system fonts if offline.

## Files

- `index.html` — page structure and invitation content
- `css/styles.css` — responsive styling, layout, and decorative artwork styles
- `js/script.js` — countdown, mobile navigation, scroll reveals, pause/resume control, and local-only RSVP preview

## Important limitation

This ZIP is a **reconstructed source project**, not an official export of the original ChatGPT-hosted site's underlying source code. The published site's private implementation and original media assets (including any palace video and custom artwork) were not available through the saved site artifact. The palace illustration here is an original inline SVG approximation. RSVP responses are only saved in the visitor's browser and are not sent to an email or backend.

Wedding details in this sample: Anna & Alexander, 12 June 2027, Schloss Nymphenburg, Munich. Replace these with final details before using it publicly.
