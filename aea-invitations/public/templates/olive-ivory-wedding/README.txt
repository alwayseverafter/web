Wedding invitation — latest published version, 19 October 2026

Run:
1. Extract this ZIP.
2. Open index.html in your browser, or serve this folder with:
   python -m http.server 8000
   Then visit http://localhost:8000

Edit index.html to change names, dates, venue, colours, layout and animation behaviour.
HTML, CSS and JavaScript are contained in index.html. No build or installation required.
Keep the media files alongside index.html.

Google Fonts and the Google Maps embed require an internet connection.
RSVP is a preview: responses are stored only in the visitor's browser, not sent to the couple.
This version includes the full-width mobile fix and continuous background fix.
It does not include the rejected tap-to-open entrance.
